# 맥북 인계: 연간 기타소득 상위 MCP

2026-10-24 사용자 최신 지시: 클라우드 대신 맥북에서 이어간다. 새 클라우드 작업을 시작하지 않는다.

PR #19의 `test/tax-annual-other-20261022` 브랜치를 최신 원격 상태와 함께 확인하고 기존 맥북 체크아웃에서 작업한다. 다른 작업을 reset하거나 force-push하지 않는다.

남은 범위는 최신 설치된 세무 공급자와 상위 MCP의 실제 연간/기존 지급 흐름 통합 검증이다. `docs/ANNUAL_OTHER_CLOUD_HANDOFF.md`의 기술적 체크리스트와 `tests/tax/annual-other-live.mjs`를 참고한다. 신규 연간 계산 9사례, 독립 음수 1사례, 입력/근거 부족 5사례, 실무자 답변 5개와 기존 지급별 검사를 유지한다. 과거 빌드/파서 보고를 현재 설치/실법령 검증으로 간주하지 않는다.

맥북에서 build와 focused 검사를 실행하고 깨끗한 설치본 및 실제 법령 근거로 required integration/live 검사를 수행한다. 인증이 없으면 비인증 작업을 완료하고 실제 조회 차단을 보고한다. 합성 근거로 live 성공을 주장하지 않는다. 검증과 리뷰가 끝나기 전 초안을 유지한다. 배포, 자동병합, 강제병합은 하지 않는다.

공개 리포/PR에는 비공개 저장소 식별자, 주소, SHA, 로컬 경로, 인증정보, 원시 비공개 응답을 넣지 않는다. 전체 시작 프롬프트와 법령/실무 인계는 비공개 공급자 리포에서 전달받는다.
